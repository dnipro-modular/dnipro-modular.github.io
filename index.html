qTone update procedure

  • 1.
    Download & install CH340 driver
    MAC WIN
    Do not install the driver on macOS 10.14 or newer. It is already built in, and installing it causes a conflict.
  • 2.
    Connect qTone via micro USB cable. The cable must support data transfer.
  • 3.
    Press Upload button.
  • 4.
    Select USB port from the list. Press "Connect".
